# Engineering docs completeness checklist

- [ ] 제품 범위와 비범위가 구분되어 있다.
- [ ] CURRENT 사실과 PROPOSED 결정을 구분했다.
- [ ] repository ownership과 contract source가 명확하다.
- [ ] ERD, SQL, RLS, retention, migration이 연결된다.
- [ ] 모든 public endpoint가 OpenAPI operationId와 Problem response를 가진다.
- [ ] PDF coordinate/object graph/event JSON Schema가 검증된다.
- [ ] FE/BE TODO에 dependency와 acceptance가 있다.
- [ ] Web/Backend/Desktop 보안 경계와 test가 있다.
- [ ] macOS sign/notarize/update/rollback이 있다.
- [ ] local Codex prompt와 push 절차가 실제 경로와 일치한다.
- [ ] 개인정보·연락처가 복제되지 않았다.
- [ ] `scripts/verify-docs.sh`가 통과한다.
