# Frontend PR checklist

- [ ] TODO ID와 acceptance가 PR에 있음
- [ ] generated contract 외 handwritten API DTO 없음
- [ ] loading/empty/error/success 상태
- [ ] keyboard/focus/accessible name
- [ ] Abort/cancel/cleanup
- [ ] Web와 Desktop 영향 검토
- [ ] PDF 변경이면 fixture/coordinate test
- [ ] Electron 변경이면 sender/origin/payload validation
- [ ] secret/PDF text/prompt/path analytics·log 없음
- [ ] unit/component/E2E evidence
- [ ] bundle size 영향
